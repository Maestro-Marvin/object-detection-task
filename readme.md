# Open-vocab scene graph — benchmark

Конвейер для **оценки понимания сцены**: по RGB-кадрам и маскам объектов строятся кропы опорных предметов, модель предсказывает, что лежит на каждой опоре, уточняется эталон (ground truth), затем предсказания сравниваются с GT — сначала по словарю синонимов, затем по семантической близости.

**Презентация:** [Open-vocab scene graph](https://docs.google.com/presentation/d/1W8wGmrX2LpFdU-KRlhVgctirt2YOT5v5It4o9Ni51NM/edit?usp=sharing)

## Как это работает

1. **Подготовка кропов и чернового GT** — по маскам выбираются опорные объекты из заданного списка id, сохраняются кропы и кандидаты в эталон из геометрии сцены.
2. **Отбор кадров** — турнирный отбор лучших кропов для каждого опорного объекта.
3. **Предсказание предметов** — VLM по отобранным кропам перечисляет объекты на/рядом с опорой.
4. **Уточнение GT** — VLM уточняет эталонный список предметов по тем же кропам и кандидатам.
5. **Оценка** — сопоставление предсказаний и GT, расчёт precision / recall / F1.

## Вход и выход

### Вход

Для одной сцены нужен каталог с четырьмя компонентами. По умолчанию в `config.py` указана сцена `scenes/scene1`:

```
scenes/scene1/
├── rgb/                                    # RGB-кадры (.jpg, .jpeg)
├── gt_instance_iphone/render_instance_npy/ # маски инстансов (.npy)
├── gt_categories.json                      # синонимы и описания объектов
└── support_ids.json                        # id опорных объектов, напр. [127, 15, 16]
```

В репозитории подготовлены сцены `scene1`–`scene4`. Чтобы запустить другую сцену, измените в `config.py`:

```python
DATA_ROOT = Path("scenes/scene2")
```

Остальные пути (`FRAMES_DIR`, `MASKS_DIR` и т.д.) вычисляются от `DATA_ROOT` автоматически.

### Выход

После `python main.py` появятся:

**`crops/`** — вырезанные фрагменты кадров по каждому опорному объекту: `crops/<id_объекта>/<имя_кадра>.jpg`.

**`results/`** — JSON с промежуточными и итоговыми результатами:

| Файл | Что внутри |
|------|------------|
| `temp_gt.json` | Черновой список предметов по каждому id (из масок, до VLM) |
| `selected_crops.json` | Пути к лучшим кропам на объект (кэш для повторного запуска) |
| `predictions.json` | Предсказанные VLM предметы по каждому id |
| `ground_truth.json` | Уточнённый эталон по каждому id |
| `report.json` | По каждому объекту: верные пары, лишние и пропущенные предметы |
| `metrics.json` | Сводные micro/macro Precision, Recall, F1 |

## Запуск

### Требования

- Linux с **NVIDIA GPU** (VLM через vLLM; при оценке дополнительно загружается embedding-модель)
- Python 3.11+

### 1. Окружение и зависимости

```bash
cd /path/to/production_task
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Данные сцены

Убедитесь, что в `DATA_ROOT` лежат `rgb/`, маски, `gt_categories.json` и `support_ids.json`, либо укажите другую сцену в `config.py` (см. раздел **Вход**).

### 3. Запуск пайплайна

```bash
python main.py
```

Скрипт последовательно выполнит все пять этапов. Прогресс отображается в консоли.

**Повторный запуск:** этап отбора кропов использует кэш в `selected_crops.json` — уже обработанные объекты пропускаются. Чтобы пересчитать отбор, удалите нужные ключи или весь файл.

Имена моделей, пороги сходства и долю кадров для GT — в `config.py`.
