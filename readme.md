# Open-vocab scene graph

Система строит **граф сцены** по последовательности фотографий комнаты: какие поверхности и мебель в кадре выступают опорой, какие предметы на них лежат, как они описаны и где именно находятся на изображении.

**Презентация:** [Open-vocab scene graph](https://docs.google.com/presentation/d/1W8wGmrX2LpFdU-KRlhVgctirt2YOT5v5It4o9Ni51NM/edit?usp=sharing)

## Как это работает

1. **Отбор кадров** — из серии снимков выбираются наиболее информативные кадры для каждой опоры (стол, полка, столешница и т.п.).
2. **Предметы на опоре** — для каждой опоры модель перечисляет связанные с ней объекты.
3. **Описания** — для каждого предмета формируется структурированное описание (форма, цвет, материал, как расположен относительно опоры).
4. **Локализация** — предметы выделяются на исходных кадрах (маски и визуализации).

## Вход и выход

### Вход

Нужна **одна сцена** — набор RGB-фотографий в одной папке. Поддерживаются файлы `.jpg` и `.jpeg`; кадры обрабатываются **в алфавитном порядке по имени файла**.

По умолчанию в `config.py` указан каталог:

```
scenes/scene2/rgb/
```

Чтобы обработать другую сцену, положите кадры в свою папку (например `scenes/my_room/rgb/`) и измените в `config.py`:

```python
DATA_ROOT = Path("scenes/my_room")
FRAMES_DIR = DATA_ROOT / "rgb"
```

В репозитории уже есть пример: `scenes/scene2/rgb/`.

### Выход

После `python main.py` появятся две папки (создаются автоматически):

**`results/`** — текстовые результаты в JSON:

| Файл | Что внутри |
|------|------------|
| `frames_by_support_raw.json` | Какие кадры отнесены к какой опоре (до отбора лучших) |
| `frames_by_support.json` | То же после отбора |
| `selected_crops.json` | Итоговый набор кадров по каждой опоре |
| `predictions.json` | Список предметов на каждой опоре |
| `detailed_predictions.json` | Подробные описания каждого предмета |

**`localization/`** — визуализация на исходных кадрах: для каждой пары «опора → предмет» создаётся подпапка с наложением маски на изображение (и бинарными масками, если это включено в конфиге).

## Запуск

### Требования

- Linux с **NVIDIA GPU** (модели VLM и SAM3 работают на видеокарте)
- Python 3.10+

### 1. Окружение и зависимости

```bash
cd /path/to/production_task
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Веса SAM3

Скачайте чекпоинт SAM3 в каталог `sam3/weights/` (ожидается файл `sam3.pt`):

```bash
pip install huggingface_hub   # если ещё не установлен
hf download 1038lab/sam3 --local-dir ./sam3/weights
```

Путь к весам задаётся в `config.py` (`SAM3_MODEL_PATH`).

### 3. Кадры сцены

Убедитесь, что в `FRAMES_DIR` лежат ваши изображения, либо обновите пути в `config.py` (см. раздел **Вход**).

### 4. Запуск пайплайна

```bash
python main.py
```

Скрипт последовательно выполнит все четыре этапа и запишет результаты в `results/` и `localization/`. Прогресс отображается в консоли.

Дополнительные параметры (модели, шаг прореживания кадров, пороги SAM3) — в `config.py`.
